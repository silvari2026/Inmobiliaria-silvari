# Silvari Inmobiliaria - Prueba de Diseño

Prueba de concepto visual para la web de Silvari Inmobiliaria, especializada en propiedades en Cienfuegos, Cuba.

## Vista Previa

Esta es una prueba estática con HTML, CSS y JavaScript puro para visualizar el diseño antes de construir la versión final con React, TypeScript y Supabase.

## Cómo Ver la Prueba

1. Sube estos archivos a un repositorio de GitHub
2. Activa GitHub Pages en Settings → Pages
3. Selecciona la rama `main` como fuente
4. La web estará disponible en `https://tuusuario.github.io/prueba-web-casas/`

## Tecnologías (Versión Final)

- React 19 + TypeScript 5.x
- Vite 6
- Tailwind CSS 4
- Supabase (Base de datos, Auth, Storage)
- Cloudflare Pages
